# Bug fix task template

Investigate and fix [observable problem].

Expected behavior: [expectation]. Actual behavior: [symptom]. Reproduction: [steps, environment, viewport, browser]. Evidence: [logs, image, failing check]. Affected scope: [known feature].

Read AGENTS and relevant feature/architecture docs. Reproduce or narrow the issue before editing. Identify the root cause, preserve unrelated working behavior, and use the smallest coherent fix.

Verify the reproduction and meaningful related behavior. Add a regression test only when it protects a real failure mode. For a visual bug, compare the affected reference state and nearby responsive widths.

Update relevant context and changelog. Record a confirmed failure and prevention in LESSONS_LEARNED; keep unconfirmed hypotheses out of factual records. Report root cause, fix, verification, and limitations.
