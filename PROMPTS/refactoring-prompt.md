# Refactoring task template

Refactor [bounded code area] to improve [specific maintainability issue] while preserving [public behavior/interfaces].

Read AGENTS, architecture, decisions, relevant components, and existing checks. Inspect actual duplication or coupling before proposing abstractions.

Scope: [files/feature boundary]. Compatibility requirements: [contracts]. Exclusions: [unrelated cleanup].

Explain the smallest structural change and architectural impact. Reuse established patterns. Avoid unnecessary rewrites, new dependencies, and feature changes. Preserve the visual reference and accessibility behavior if UI is affected.

Run relevant checks and compare observable behavior before/after. Update architectural and component documentation if boundaries change, then provide a concise explanation and verification evidence.
